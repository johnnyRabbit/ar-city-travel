# 🏛️ Évora Through Time

Jogo histórico de exploração onde descobres locais históricos enquanto foges de zombies!

## 🎮 Como Jogar

1. **Clica em "Começar Aventura"** para iniciar
2. **Move-te** pelo mapa de Évora
3. **Descobre locais históricos** aproximando-te e clicando nos markers
4. **Elimina zombies** clicando neles
5. **Filtra por era** usando o seletor de tempo no topo

## 🗺️ Características

- **Mapa interativo** de Évora com Leaflet
- **8 locais históricos** reais da cidade
- **Zombies** que te perseguem
- **Filtro por era** (Romano, Medieval, Renascimento, Moderno)
- **Sistema de pontos** e níveis
- **Interface mobile-friendly**

## 📜 Locais Históricos

### Romano
- 🏛️ Templo Romano (século I)
- ♨️ Termas Romanas (século II)

### Medieval
- ⛪ Sé Catedral (1189-1250)
- 💀 Igreja de São Francisco (século XV)

### Renascimento
- 🎓 Universidade de Évora (1559)
- 🌊 Aqueduto da Água da Prata (1537)

### Moderno
- 🏪 Praça do Giraldo (século XVI)
- 💣 Cerco de Évora (1808)

## 🛠️ Tecnologias

- **React 18** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS** (estilos)
- **Leaflet** + **react-leaflet** (mapas)
- **Zustand** (state management)

## 🚀 Como Executar

```bash
# Instalar dependências
npm install

# Executar em modo desenvolvimento
npm run dev

# Build para produção
npm run build
```

## 📱 Controlos

### Desktop
- **WASD** ou **Setas** - Mover jogador
- **Clica** nos markers - Interagir

### Mobile
- **GPS** - Posição real
- **Toque** - Interagir com markers

## 🎯 Objetivos

- Descobrir todos os 8 locais históricos
- Eliminar zombies para ganhar pontos
- Explorar todas as eras históricas
- Alcançar o nível máximo!
